# API reference

_Generated by `tools/gen_api_docs.py` from the source doc comments — do not edit by hand._

All element and widget methods are called on `St` (the `st` passed to your app function) or on a
container returned by it (`st.sidebar`, `st.columns(2)[0]`, `st.expander("...")`, ...).
Optional parameters are usually passed by name: `st.slider("x", 0, 10, 5, step: 2, key: "s")`.

## Partial reruns: fragments, dialogs, status

Source: [`source/streamlitd/fragments.d`](../source/streamlitd/fragments.d)

#### `final class StatusContainer`
Handle returned by `st.status`: a container (use it like `st`) whose label/state can change.

```d
void update(string label = null, string state = null, int expanded = -1)
```
Change label, state ("running", "complete", "error") and/or expansion (-1 = keep, 0/1).

```d
void fragment(void delegate(St) body_, double runEvery = 0, string key = null)
```
`st.fragment`: the body reruns on its own when a widget inside it changes, without rerunning the whole app. `runEvery` (seconds) reruns it periodically (live dashboards). Pass a lambda `(St f) { ... }`; for a named function use `toDelegate(&fn)`.

```d
void dialog(string title, void delegate(St) body_, string width = "small", bool dismissible = true, string key = null)
```
`st.dialog`: shows a modal dialog. Its widgets rerun only the dialog. The dialog stays open while it reruns and closes on the next full rerun in which it is not opened again (e.g. after `st.rerun()`), or when the user dismisses it.

```d
StatusContainer status(string label, bool expanded = false, string state = "running")
```
`st.status`: an expandable container showing the state of a long task.
